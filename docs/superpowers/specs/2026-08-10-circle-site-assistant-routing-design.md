# サークル・サイト専用AIアシスタント再設計

## 目的

AIアシスタントの回答対象を、TTI Intelligence（AIサークル）と、このWebサイトに掲載している内容・使い方に限定する。対象外の質問ではLunaを呼ばず、短い案内だけを返す。豊田工業大学全般について詳しい説明は生成せず、大学公式サイトを案内する。

## 回答範囲

### Lunaで回答する

- TTI Intelligenceの概要、活動、参加方法、Discord、YouTube、制作物
- このWebサイトのページ、機能、使い方、掲載されたお知らせやコンテンツ
- サイト内の開発解説として掲載しているCodex、Vercel、AWS、Plugin、CLI、MCP
- 上記の話題に対する、直前の会話を受けた明確な追加質問

Lunaへ渡す根拠は、質問に関係するサークル資料またはサイト資料だけに限定する。回答はLINEの会話のように、結論から原則200文字以内、最大280文字とする。Web検索は使わない。

### Lunaを呼ばずに回答する

1. 豊田工業大学全般
   - 回答文: `豊田工業大学については、公式サイトをご確認ください。`
   - リンク: `https://www.toyota-ti.ac.jp/`
   - 入試、学費、学部、アクセス、大学全体の課外活動などを詳しく説明しない。
2. 対象外の一般質問
   - TTI Intelligenceとこのサイトについて案内できることを短く伝える。
   - 外部サイトや問い合わせ先へ不要に誘導しない。
3. 挨拶、感謝、終了表現
   - 自然な短文を返す。

## 質問の振り分け

Lambda内で、OpenAI APIを使わない決定的なスコープ判定を最初に行う。判定結果は次の5種類とする。

- `circle`: サークルに関する質問
- `site`: サイト、掲載ページ、掲載技術に関する質問
- `university`: 豊田工業大学全般に関する質問
- `conversation`: 挨拶や感謝
- `out_of_scope`: その他

優先順位は `circle`、`site`、`university`、`conversation`、`out_of_scope` とする。「このサークル」「AIサークル」「TTI Intelligence」は必ず `circle` を優先する。現在表示中のページと直前の利用者メッセージは、「これ」「ここ」「参加したい」などの省略された追加質問を補う場合だけ使う。曖昧で対象内と確認できない質問は、安全側に倒して `out_of_scope` とする。

大学名とサークル語が同時に含まれる場合でも、質問の中心がTTI Intelligenceなら `circle` とする。大学の公式性や大学制度そのものを尋ねる質問は `university` とする。

## API呼び出しとデータフロー

1. リクエスト形式、文字数、オリジンを検証する。
2. ローカルのスコープ判定を行う。
3. `university`、`conversation`、`out_of_scope` は、その場で固定の安全な応答を返す。Secrets Manager、動的コンテンツ検索、Lunaは呼ばない。
4. `circle` または `site` の場合だけ利用枠を確保する。
5. 対象スコープに必要な構造化資料を選ぶ。動的コンテンツ検索は `circle` または `site` のうち、お知らせ、掲示板、今週の数学など公開後に更新される内容を尋ねた場合だけ行う。
6. Secrets ManagerからAPIキーを取得し、Lunaを1回だけ呼ぶ。`tools: []` を維持し、Web検索は使わない。
7. 出力を検証し、許可済みリンクだけを返す。

この構成により、大学全般、一般質問、挨拶ではOpenAI料金が発生しない。サークルまたはサイトの質問では、回答生成のためにLunaを1回だけ呼ぶ。

## 知識資料

- サークル資料は、TTI Intelligenceに関する事実だけを保持する。
- サイト資料は、公開ページ、機能、掲載中の技術解説を保持する。
- 大学の詳細資料はLunaへ渡さない。大学全般は公式サイト案内だけにする。
- Codex、Vercel、AWS、Plugin、CLI、MCPは、サイトに掲載している範囲を根拠に説明する。
- リンクは既存の許可リストに加え、大学公式トップ `https://www.toyota-ti.ac.jp/` を完全一致で許可する。

## エラーと安全性

- Lunaが失敗した場合、サークル・サイト情報を推測で補わず、一時的に回答できない旨だけを返す。
- モデル出力内のURLは採用せず、サーバー側の許可済みリンクだけを返す。
- プロンプトインジェクション対策、履歴件数制限、入力長制限、回答最大280文字を維持する。
- スコープ判定結果、Luna呼び出し回数、選択資料数を個人情報なしで記録する。

## UI文言

初期メッセージは、AIが「TTI Intelligenceとこのサイトについて案内する」ことを明示する。一般知識や大学全般を詳しく回答する印象を与える文言は削除する。

## テストと完了条件

- 「このサークルについて教えて」は `circle` になり、Lunaを1回呼び、サークル資料だけを渡す。
- 「このサイトは何？」「掲示板の使い方」「Codexとは？」は `site` になり、Lunaを1回呼ぶ。
- 「豊田工業大学について教えて」「学費は？」は、大学の文脈が明確な場合 `university` になり、Lunaを0回、大学公式トップへの案内を返す。
- 「東京の天気は？」「プログラミングを教えて」は `out_of_scope` になり、Lunaを0回にする。
- 「こんにちは」「ありがとう」は `conversation` になり、Lunaを0回にする。
- 「それに参加したい」のような追加質問は、直前がサークルの話題なら `circle` を維持する。
- 大学全般の応答は280文字を超えず、大学の詳細情報を生成しない。
- 対象外応答に大学公式リンクや無関係なサイトリンクを付けない。
- 既存の入力検証、リンク安全性、利用枠、安全性、プライバシーの全テストを維持する。
- 本番確認では、サークル質問、サイト質問、大学質問、対象外質問を各1件送り、期待するLuna呼び出し回数と応答をログで確認する。

## 対象外

- Web検索の追加
- 豊田工業大学の詳細FAQ作成
- 一般用途のチャットAI化
- Luna以外のモデルへの切り替え
- フロントエンドの大規模な見た目変更
