# 単色カーソル・反復デモ・Architectureステッパー — デザイン仕様

## 目的

`/development` のCodex操作デモを、画面内に表示されている間だけ繰り返し再生できる体験へ変更する。同時に、System Architectureを小さな補助表示ではなく、現在の処理段階と残り工程が読める大型ステッパーへ変更する。

## カーソル

- 色は薄いアイスブルー `#BDEBFF` の単色とする。
- 塗りは約35%の透明度、輪郭は同色の約85%とする。
- グラデーション、黒または濃紺の輪郭、紫色の発光は使用しない。
- 影とクリック波紋も `#BDEBFF` だけを透明度違いで使用する。
- カーソルはCodexウィンドウ内だけでなく、Architectureステッパーまで移動できるステージ全体の座標系で動かす。

## Architectureステッパー

### デスクトップ

- ステッパーの高さは約100px、横幅はCodexウィンドウと揃える。
- Codexウィンドウを上へ移動し、両者が重ならない空間を確保する。
- 上部に `STEP N OF 5` を表示する。
- 中央に5段階を横並びで表示する。
- 現在のステップは他より横幅を広げ、番号、タイトル、1行説明を表示する。
- 未到達ステップは番号と短いタイトルだけを表示する。
- 完了ステップは番号をチェックマークへ変更する。
- 下部に太めの進捗線を表示し、現在位置までアイスブルーで塗る。

### モバイル

- ステッパーの高さは約92pxとする。
- 上段に5つの番号と短いタイトルを並べる。
- 下段に現在のステップ名と説明を大きく表示する。
- 5枚の説明カードを横に詰め込まない。

### 高さ520px以下

- ステッパーの高さは約58pxとする。
- 説明文を省略し、番号、短いタイトル、進捗線だけを表示する。
- Codexウィンドウとステッパーを同一ビューポート内に維持する。

## 操作シーケンス

1. 初期状態では `01 Instruction` だけを強調する。
2. カーソルがArchitectureステッパーの `01` へ移動する。
3. カーソルが `01` をクリックし、進捗線が動き始める。
4. カーソルがCodex入力欄へ移動し、指示を入力する。
5. Codex画面の出来事に合わせてステップを進める。

   - `01 Instruction`：指示を入力
   - `02 Context`：対象ファイルと履歴を読み込む
   - `03 Execute`：計画、編集、コマンドを実行
   - `04 Review`：Diffとレビュー対象を表示
   - `05 Verify`：テストと画面サイズ検証を完了

6. `05 Verify` の完了状態を1.5秒表示する。
7. 0.5秒で操作結果と進捗を薄くフェードする。
8. 初期状態へ戻し、カーソルが再び `01` をクリックして次のサイクルを開始する。

## 反復制御

- デモ全体は約11秒のサイクルとして繰り返す。
- ステージがビューポート内に55%以上表示されている間だけ再生する。
- ステージが画面外へ出た場合は、すべてのタイマーを停止して初期状態へ戻す。
- 再び55%以上表示された場合は、途中からではなく `01` のクリックから再生する。
- タブが非表示になった場合も停止し、表示へ戻った時点で初期状態から再生する。
- Architectureステッパーに再生／一時停止ボタンを設置する。
- 利用者が一時停止した場合は、画面外へ出入りしても自動再開しない。再生ボタンを押した場合だけ再開する。

## 軽減モーション

- `prefers-reduced-motion: reduce` ではカーソル移動と自動ループを無効にする。
- Codexの完了状態、5つのステップ、`STEP 5 OF 5`、完了済み進捗線を静的に表示する。
- 再生／一時停止ボタンは表示しない。

## 状態管理

反復制御は次の状態を明示的に管理する。

- `idle`：初期状態
- `playing`：タイマー実行中
- `holding`：完了状態を表示中
- `resetting`：次のサイクルへ戻している
- `paused`：利用者が一時停止した状態

サイクル開始時は前回のタイマーをすべて破棄し、表示クラス、入力文字列、Diff、テスト結果、Architecture進捗を初期化する。同じタイマーが二重に動作しないよう、サイクル番号を各コールバックで照合する。

## 検証条件

- カーソルのSVGにグラデーション定義が存在しない。
- カーソルの塗り、輪郭、影、クリック波紋が `#BDEBFF` の透明度違いだけで構成される。
- 1サイクル内で `01 → 02 → 03 → 04 → 05` が順番に1回ずつ強調される。
- 2サイクル目でもカーソルが `01` をクリックしてからCodex操作が始まる。
- 一時停止中はステップ、カーソル、入力文字列が変化しない。
- 画面外ではタイマーが停止し、再入場時は `01` から始まる。
- 390×844、844×390、1280×720でCodexウィンドウとステッパーが重ならず、ビューポートからはみ出さない。
- モバイルで現在のステップ説明が判読できる。
- 軽減モーション時にループせず、5段階の情報が欠落しない。

## 対象外

- Architectureステップをクリックして任意位置へ移動するスクラブ機能
- 実際のCodex、リポジトリ、バックエンドとの接続
- 画面外でも継続するバックグラウンドアニメーション
