# TTI Intelligence UIプレビュー

Appleのような余白、タイポグラフィ、自然な写真を試すための別フォルダです。
元サイトのソースや公開環境は変更しません。

## 開く

```bash
cd ui-preview
npm run dev
```

<http://127.0.0.1:4174/about> がサークル紹介、<http://127.0.0.1:4174/> がホームです。
初回に依存関係がない場合は、元サイトの `frontend` で `npm ci` を実行してください。

## 共通の内容・機能

- `frontend/src/App.tsx` と全ページを直接読み込むため、ニュース一覧・記事本文・フォームの入力項目・入力チェック・リンクは元サイトと同じです。元サイトの変更もプレビューに反映されます。
- `frontend/public` の画像・動画と `frontend/.env*` の接続設定を共有します。環境変数や認証情報はこのフォルダへコピーしません。
- お問い合わせを送信すると、元サイトと同じEmailJSの送信先へ実際に送信されます。掲示板・管理画面の更新も同じ接続先に作用します。UI確認では送信や更新を実行しないでください。
- 検証ではメール送信をせず、入力と入力チェックを確認します。

## プレビューだけの変更

- `src/preview.css`: 白・薄いグレーの背景、余白、見出し、カード、ナビゲーション、フォームの見た目。
- `activity-photos.ts`: 紹介ページの4枚をフリー素材の実写に差し替え。ライト／ダークで同じ写真を表示します。
- `vite.config.ts`: 紹介ページだけに写真の差し替えを適用。文章やデータ処理はそのまま使います。
- ページ上部の「写真の出典」から撮影者・素材ページを確認できます。

素材は外部サイトから表示するため、インターネット接続が必要です。
現在の写真は候補であり、メンバーや実際の活動風景を撮影したものではありません。

## ビルド

```bash
npm run build
npm run preview
```

生成先はこのフォルダ内の `dist` です。プレビューを公開する設定は追加していません。
